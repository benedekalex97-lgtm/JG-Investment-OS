Bevezetési sorrend (éles, egyenként jóváhagyott lépések; a tulajdonosi `DATABASE_URL`-lel, `JG_ENV=production`):

```bash
# 1. friss Neon ág + titkosított mentés (lásd C), majd a 0011 + 0012 migráció
JG_CONFIRM_PRODUCTION=yes npm run db -- migrate
# 2. a v1.3 alkalmazás deploymentje (Vercel, kézi; fra1 régió)
# 3. a két új fiók (Google-belépés; jelszó csak a helyi módhoz kell, élesben nem használható)
JG_USER_PASSWORD='<véletlen, min. 12 karakter>' npm run db -- user:create alex@axflowdigital.hu "<név>"
JG_USER_PASSWORD='<véletlen, min. 12 karakter>' npm run db -- user:create lengyel.gabor@jginvst.com "Lengyel Gábor"
# 4. jogok
export JG_OPERATOR="<üzemeltető>" JG_CONFIRM_PRODUCTION=yes
npm run db -- permission:grant alex@axflowdigital.hu crm.privacy.manage
npm run db -- permission:grant lengyel.gabor@jginvst.com crm.privacy.manage
npm run db -- permission:grant info@jginvst.com crm.privacy.manage
npm run db -- permission:grant info@jginvst.com crm.privacy.erase
npm run db -- permission:list
```

A 4. lépés a felületen is elvégezhető (Beállítások › Felhasználók és jogosultságok): az `info@jginvst.com` `crm.users.manage` joggal
kiadhatja a felelős és a helyettes jogát, de **a saját jogait nem** (önjogosítás tiltva) — az `info@jginvst.com` két adatvédelmi jogát
a CLI-ből vagy egy másik felhasználókezelő adminnak kell kiadnia.

A személyeknek aktív CRM-felhasználónak kell lenniük (Google-belépés). Évente felülvizsgálandó, kinek van joga.

## B. Adatfeldolgozói szerződések (GDPR 28. cikk)

- [ ] **Vercel** (alkalmazás-futtatás): a Vercel adatfeldolgozói kiegészítését (Data Processing Addendum) a csapat (team) nevében
      elfogadni / letölteni és archiválni; az al-adatfeldolgozók listáját elmenteni. A függvények régiója a kódban rögzítve:
      `vercel.json` → `"regions": ["fra1"]` (Frankfurt) — a következő deploymentnél érvényes; utána a Vercel projekt
      beállításaiban (Functions › Region) ellenőrizni.
- [ ] **Neon** (adatbázis): a Neon adatfeldolgozói kiegészítését (DPA) elfogadni / archiválni. Régió: `aws-eu-central-1` (Frankfurt) —
      mindkét projektnél ellenőrizve (2026-11-25).
- [ ] **Google** (munkatársi belépés, OAuth-kliens a Google Cloud projektben): a Google Cloud adatfeldolgozási feltételeit

      Google-hoz, csak a munkatársak belépési azonosítója.
