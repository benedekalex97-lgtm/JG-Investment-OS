# Adatvédelmi bevezetési ellenőrzőlista (v1.3) — jogosultságok, szerződések, mentések

> A 2026-11-25-én jóváhagyott döntések végrehajtása. A kódban megvalósítható rész kész (négy-szem elv, jogalap- és megőrzési szöveg,
> státuszfüggő megőrzés, Vercel EU-régió). Az alábbi lépések valós személyekhez, szerződésekhez vagy éles infrastruktúrához kötöttek,
> ezért a tulajdonos (vagy megbízottja) végzi el őket; mindegyik pipálható.

## A. Jogosultsági terv (jóváhagyva)

| Szerep | Személy (kitöltendő) | Jog | Megjegyzés |
| --- | --- | --- | --- |
| Adatvédelmi felelős | ____________ (e-mail) | `crm.privacy.manage` | érintetti kérelmek, kivonat, tiltakozás, megőrzési felülvizsgálat |
| Adatvédelmi helyettes | ____________ (e-mail) | `crm.privacy.manage` | szabadság/távollét esetére — az 1 hónapos határidő miatt kötelező |
| Törlést jóváhagyó vezető (pl. ügyvezető) | ____________ (e-mail) | `crm.privacy.erase` (+ `crm.privacy.manage` a felülethez) | csak ő hajthat végre végleges törlést |

**Négy-szem elv (kódban kikényszerítve, az adatbázis is ellenőrzi):** a törlési kérelmet rögzítő felhasználó nem hajthatja végre a
végleges törlést — a felelős / helyettes rögzíti és azonosítja, a vezető törli. Ezért a vezető ne legyen egyben az egyetlen rögzítő.

Kiosztás (a v1.3 migráció UTÁN, a tulajdonosi kapcsolattal; élesben `JG_CONFIRM_PRODUCTION=yes`), vagy a felületen
(Beállítások › Felhasználók és jogosultságok, `crm.users.manage` joggal):

```bash
JG_OPERATOR="<üzemeltető>" npm run db -- permission:grant <felelős e-mail> crm.privacy.manage
JG_OPERATOR="<üzemeltető>" npm run db -- permission:grant <helyettes e-mail> crm.privacy.manage
JG_OPERATOR="<üzemeltető>" npm run db -- permission:grant <vezető e-mail> crm.privacy.manage
JG_OPERATOR="<üzemeltető>" npm run db -- permission:grant <vezető e-mail> crm.privacy.erase
npm run db -- permission:list
```

A személyeknek aktív CRM-felhasználónak kell lenniük (Google-belépés). Évente felülvizsgálandó, kinek van joga.

## B. Adatfeldolgozói szerződések (GDPR 28. cikk)

- [ ] **Vercel** (alkalmazás-futtatás): a Vercel adatfeldolgozói kiegészítését (Data Processing Addendum) a csapat (team) nevében
      elfogadni / letölteni és archiválni; az al-adatfeldolgozók listáját elmenteni. A függvények régiója a kódban rögzítve:
      `vercel.json` → `"regions": ["fra1"]` (Frankfurt) — a következő deploymentnél érvényes; utána a Vercel projekt
      beállításaiban (Functions › Region) ellenőrizni.
- [ ] **Neon** (adatbázis): a Neon adatfeldolgozói kiegészítését (DPA) elfogadni / archiválni. Régió: `aws-eu-central-1` (Frankfurt) —
      mindkét projektnél ellenőrizve (2026-11-25).
- [ ] **Google** (munkatársi belépés, OAuth-kliens a Google Cloud projektben): a Google Cloud adatfeldolgozási feltételeit
      (Cloud Data Processing Addendum) a Cloud Console adatvédelmi / megfelelőségi beállításainál elfogadni; ügyféladat nem kerül a
      Google-hoz, csak a munkatársak belépési azonosítója.
- [ ] Mindhárom szolgáltatónál: EU-US adattovábbítás alapja (EU-US Data Privacy Framework tanúsítás és / vagy általános szerződési
      feltételek) — a szerződésekben ellenőrizni és a 30. cikk szerinti nyilvántartásba beírni.
- [ ] A szerződések helye: ____________ (hozzáférés-védett dokumentumtár).

## C. Mentések (jóváhagyott rend: 35 nap gördülő + 12 havi mentés)

Ehhez két döntés kell (a kód kész: titkosított `backup`, `backup:verify`, `privacy:ledger`):

- [ ] **Tárhely:** hozzáférés-védett, EU-beli tároló a `.jgbackup` fájloknak — pl. külön felhőtároló bucket (EU régió, verziózással,
      csak az üzemeltetők elérésével) vagy céges, titkosított meghajtó. Választás: ____________
- [ ] **Kulcs:** a mentési kulcs (`npm run db -- backup:keygen`) jelszókezelőben, legalább két üzemeltetőnél, a mentésektől külön.
      Jelszókezelő: ____________
- [ ] **Neon:** ütemezett snapshot bekapcsolása és a visszaállítási ablak (most 6 óra) bővítése a csomag szerint — külön jóváhagyott
      infrastruktúra-módosítás.
- [ ] Minden mentés mellé friss törlési napló: `npm run db -- privacy:ledger <fájl>`; visszaállítás után `privacy:reapply`.
